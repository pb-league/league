How to connect Google Sheets & Google Drive

  1. Create a Google Sheet with these exact column headers in row 1:
    name | address | phone | age | interests | photo_url | lat | lng | pin_color
  2. Publish the sheet: File → Share → Publish to web → CSV → Publish. Copy the URL.
  3. Enable Google Sheets API at console.cloud.google.com, create an API key, and restrict it to Sheets API + your domain.
  4. For photos: Upload images to a shared Google Drive folder. Right-click → Get link → set to "Anyone with link". Convert the share link to a direct image URL:
    https://drive.google.com/uc?export=view&id=FILE_ID
  5. For writing new pins (optional): Use a Google Apps Script Web App as a proxy to handle POST requests and append rows. Deploy it as a web app with execute permissions set to "Anyone".
  6. Update the CONFIG section in the <script> at the bottom of this file with your Sheet ID and API key.

Demo mode: The app loads sample pins from the DEMO_PINS array in the script. Once you configure your Sheet, it will read live data from Google Sheets.
